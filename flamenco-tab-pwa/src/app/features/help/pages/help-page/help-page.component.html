Guía de uso

Cómo usar FlamencoTab

FlamencoTab es un editor de tablaturas de guitarra flamenca que funciona como aplicación web (PWA): no necesita cuenta ni conexión y guarda todo en tu dispositivo. Esta guía explica cómo crear y editar tablaturas, usar los ornamentos flamencos, gestionar acordes y exportar o imprimir tu trabajo.

1 Primeros pasos

La aplicación se organiza en tres secciones, accesibles desde la barra superior:

Tablaturas

Tu lista de tablaturas. Desde aquí creas una nueva, importas un JSON, exportas o eliminas.

Editor

Donde se compone. Abre la última tablatura editada o una nueva si no hay ninguna.

Acordes

Biblioteca de acordes flamencos en nomenclatura española (DO, RE, MI, FA, SOL, LA, SI).

Autoguardado. No hay botón de guardar: cada cambio se guarda solo, con una pequeña espera de medio segundo. Todo se almacena en tu navegador.

2 El editor

Barra superior

  • Título, palo y tonalidad: datos de la tablatura que aparecen en la cabecera y en la impresión.
  • Exportar JSON: descarga la tablatura como archivo (copia de seguridad o para otro dispositivo).
  • Exportar PDF: genera un PDF listo para guardar o compartir.
  • Imprimir: abre un diálogo con las opciones de impresión.
  • Importar: carga un archivo JSON exportado antes.
  • Panel de notas: muestra siempre el panel de entrada de trastes (útil en tablet o escritorio).
  • Limpiar: borra todo el contenido de la tablatura actual (pide confirmación).

Bloques

Una tablatura se divide en bloques (por ejemplo, introducción, falseta, estribillo). Cada bloque tiene:

  • Título editable para nombrarlo.
  • Colapsar / expandir para ocultarlo y ahorrar espacio.
  • Subir / bajar para reordenar bloques.
  • Duplicar para copiar el bloque completo.
  • Eliminar (con confirmación).
  • Añadir líneas para crear una nueva tanda dentro del bloque.

Tandas de líneas

Dentro de cada bloque puedes tener varias tandas de seis líneas (los pentagramas de guitarra). Cada tanda se puede:

  • Subir, bajar, duplicar o eliminar con los iconos de su cabecera.
  • Añadir o quitar columnas con – y +, junto al contador de columnas.
  • Insertar una columna antes o después de la seleccionada y eliminar la columna seleccionada. Estos iconos solo aparecen en la línea que tiene una celda seleccionada.

Columnas y etiquetas

Cada columna es un instante de tiempo. Bajo la tablatura hay un campo de etiqueta por columna, ideal para anotar el acorde o el número de compás.

3 Introducir notas

  1. Selecciona una celda: toca la intersección de una cuerda y una columna. La celda se resalta en azul.
  2. Escribe el traste con el panel de notas (móvil) o el teclado (escritorio). Se admiten de 0 a 24 y la marca X.
  3. La nota aparece sobre la línea de la cuerda correspondiente.

Panel de notas

En móvil aparece abajo al seleccionar una celda. Sus botones son:

  • ▲ / ▼: sube o baja un traste.
  • 0 – 12: escribe ese traste directamente.
  • X: marca la cuerda como no tocada.
  • Borrar (icono de retroceso): deja la celda vacía.

Si no cabe en la pantalla, puedes desplazar el panel horizontalmente.

La tablatura flamenca no usa figuras de duración (corcheas, negras…): la duración se expresa mediante la posición de las notas.

4 Ornamentos flamencos

Cómo se insertan

  • Selecciona una celda y pulsa el botón del ornamento en la barra de ornamentos.
  • O mantén pulsada una celda (más de medio segundo) para abrir el menú rápido de ornamentos.

Ligaduras

Una ligadura se forma con dos ornamentos: Ligadura inicio en la primera nota y Ligadura fin en la última. Se dibuja un arco entre ambas. Puedes pulsar el arco para seleccionarlo.

Trémolo

Selecciona una celda y pulsa Trémolo (o Mayús + T). La nota se repite cuatro veces y aparece un editor para escribir los cuatro trastes. Vuelve a pulsarlo para quitarlo.

Eliminar un ornamento

Pulsa sobre el ornamento en la tablatura para seleccionarlo y usa el menú de acciones que aparece.

Los ornamentos se dibujan a la derecha de la nota con una separación fija, y la columna se ensancha solo lo necesario para que no se solapen con la siguiente.

5 Acordes

La sección Acordes guarda las posturas en nomenclatura española (DO, RE, MI, FA, SOL, LA, SI), con los palos recomendados para cada una.

  • Nuevo acorde: crea una postura personalizada (nombre, nota raíz, palos y traste por cuerda).
  • Restablecer: elimina los acordes personalizados y conserva los predefinidos.
  • Importar en la tablatura: selecciona una columna y pulsa Acorde en la barra de ornamentos; elige el acorde y se colocarán todas sus notas.

6 Exportar, importar e imprimir

Exportar JSON

Descarga la tablatura como archivo. Úsalo como copia de seguridad o para pasarla a otro dispositivo.

Importar

Carga un archivo JSON exportado antes. También puedes importar desde la lista de tablaturas.

Exportar PDF

Genera un PDF con la tablatura, listo para guardar o compartir.

Imprimir

Abre un diálogo con la orientación y los datos que quieres incluir.

Opciones de impresión

  • Orientación: vertical o apaisado.
  • Incluir título y palo y tonalidad.
  • Autor: se muestra bajo el título.
  • El pie de página incluye el nombre de la tablatura y el número de página (X / Y).

7 Panel de notas

En móvil, el panel de notas aparece automáticamente al seleccionar una celda. En tablet o escritorio está oculto por defecto, pero puedes forzarlo con la casilla Panel de notas de la barra superior.

La preferencia se recuerda entre sesiones.

8 Instalación y datos

  • Instalar como app: usa «Añadir a pantalla de inicio» del navegador. Se abrirá a pantalla completa.
  • Sin conexión: funciona offline. El contenido se cachea y tus datos se guardan en el dispositivo.
  • Actualizaciones: cuando hay una versión nueva, aparece un aviso para actualizar.
  • Copia de seguridad: como los datos viven en el navegador, exporta a JSON de vez en cuando.

10 Consejos

  • Usa las etiquetas de columna para indicar acordes o compases.
  • Organiza la tablatura en bloques para separar secciones.
  • Exporta a JSON antes de hacer cambios grandes.
  • En móvil, gira el dispositivo a horizontal si necesitas ver más columnas a la vez.
